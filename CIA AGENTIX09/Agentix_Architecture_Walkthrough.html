Agentix Universal Architecture

GLOBAL OVERVIEW
Architectural Role & Description

Agentix is an AI-powered agentic data intelligence platform designed to eliminate the barrier between raw tabular data and actionable, explainable insights. It couples deterministic Python/scikit-learn processing with grounded local and cloud LLM synthesis across 7 decoupled architectural tiers.

Core Engineering Principle
Deterministic Math, Grounded Narrative: All statistical summaries, missing value treatments, 5-fold cross-validation, and metrics are calculated strictly by deterministic Python algorithms. LLMs are never permitted to generate or guess numerical data.
Technical Stack & Protocols Next.js 15, FastAPI 0.115, scikit-learn, XGBoost, LightGBM, SHAP, Ollama, Neon PostgreSQL, Apache Parquet
Source Implementation Paths frontend/src/* • backend/core/*
Security & Architectural Boundaries

Multi-tenant isolation verified with FastAPI dependency injection; BFF token relay prevents client secret exposure; Layer 6 GuardrailEngine sanitizes PII and jailbreak patterns.

Each autonomous agent owns a strictly bounded data science responsibility within backend/core/agents/, executed sequentially in background threads with zero cross-agent state pollution.

1. Deterministic Analytics vs. LLM

MATHEMATICAL RELIABILITY

The Problem: When LLMs calculate averages, standard deviations, or correlation matrices directly from prompt text, they exhibit high rates of floating-point hallucination and non-reproducibility.

The Agentix Solution: Strict division of labor:
• Deterministic Python Engine: Polars, NumPy, and scikit-learn compute mathematical transformations, model metrics, and statistical tests.
• LLM Synthesis Engine: The LLM acts solely as a linguistic translator, generating human-readable narrative explanations grounded in verified numeric inputs.

2. Backend-for-Frontend (BFF) Token Relay

ZERO-XSS SECURITY BOUNDARY

The Problem: Storing JWT bearer tokens or API secrets in browser localStorage leaves the application vulnerable to cross-site scripting (XSS) credential exfiltration.

The Agentix Solution:
1. Client signs in via Auth.js v5; session credentials stored in an encrypted, HttpOnly, SameSite=Lax cookie.
2. Outgoing backend calls are intercepted by /api/auth/token (BFF route handler running server-side on Vercel).
3. The BFF verifies the cookie server-side, attaches the backend secret, and transparently proxies the request to FastAPI. Browser JavaScript never touches backend credentials.

3. 3-Tier Explainable AI (XAI) Fallback

FAULT-TOLERANT EXPLAINABILITY

The Problem: SHAP computations on large datasets or complex ensembles can cause memory exhaustion or API timeouts.

The Agentix Solution (3 Tiers):
• Tier 1 (Exact): TreeSHAP / KernelSHAP computes exact Shapley values. A strict 15-second timeout watchdog monitors execution.
• Tier 2 (Surrogate): If Tier 1 times out or fails, an interpretable surrogate Decision Tree is fitted to the ensemble's predictions to extract feature importance and decision rules.
• Tier 3 (Statistical): If surrogate fitting fails, the system falls back to Pearson and Spearman correlation coefficients from EDAAgent. Zero unexplainable predictions.

Sub-5ms LLMCache Efficiency

LAYER 7 PERFORMANCE

By computing cryptographic SHA-256 hashes over normalized prompt payloads and temperature parameters, Layer 7's LLMCache intercepts identical requests and delivers cached responses in under 5 milliseconds with zero cloud egress cost and zero token consumption.

Hardware Inference & Privacy Caveat

CRITICAL COMPLIANCE NOTICE

Local Inference Support: Agentix supports on-device local execution via Ollama (qwen2.5-coder, mistral, llama3) accelerated by Apple Silicon Metal or NVIDIA CUDA.

Configurable Cloud Fallback: The platform also supports configurable fallback to cloud LLM APIs (Google Gemini, OpenAI, Anthropic Claude). On publicly hosted deployments (Vercel frontend and Render backend), cloud egress is enabled.

Therefore, Agentix must not be described as unconditionally "air-gapped" unless deployed on dedicated on-premise hardware with cloud fallback explicitly disabled.

Disclosed Engineering Limitations

TRANSPARENT STATUS

• Binary PDF Generation: Currently, direct binary PDF report downloads return structured JSON (pdf_available: false). Full WeasyPrint binary PDF rendering is staged for subsequent release.
• Delta Lake Rollback: Time-travel rollback is architected on the roadmap; current production utilizes Snappy-compressed Apache Parquet snapshots.
